- utiliser un `$state` pour faire descendre la vie du Pokémon en cliquant sur le bouton
- vous pouvez utilisez la fonction utilitaire `getRandomNumber` importée depuis
  `#lib/utils/getRandomNumber.js`
- la vie ne peut pas être inférieure à 0
