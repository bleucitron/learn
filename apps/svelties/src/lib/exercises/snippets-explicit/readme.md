Les snippets peuvent être fournis à des composants en tant que props, ce qui permet de facilement
personnaliser le markup d'un composant. Ils peuvent être passés en tant que props soit de manière
explicite, soit de manière implicite.

- créer deux snippets différents permettant d'afficher les PV d'un Pokémon
- fournir ces snippets en tant que props de manière explicite
